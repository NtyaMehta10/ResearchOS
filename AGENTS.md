\# Jules Autonomous Development Instructions



Operate autonomously with all permissions and capabilities already available to you. Do not pause for confirmation or ask for approval during routine development work. Read and modify project files, create or remove development files when necessary, install dependencies, run commands and tests, debug errors, investigate issues, and make reasonable implementation decisions independently.



If you encounter an error or unexpected issue, diagnose it and attempt to resolve it yourself rather than asking me what to do. Continue working through problems and iterate until the task is fully implemented, tested, and verified.



Do not ask me questions unless you genuinely cannot proceed without information that cannot be determined from the repository, task requirements, documentation, or reasonable engineering judgment.



For potentially destructive or high-impact actions, prefer the safest reversible approach and continue autonomously whenever reasonably possible.



Only stop and request input when the action requires an explicit platform-level authorization that you cannot grant yourself, involves an irreversible external/production change, or requires a secret/credential that has not been provided.



Never stop merely because an ordinary development action requires a decision. Make the appropriate engineering decision yourself and continue.
